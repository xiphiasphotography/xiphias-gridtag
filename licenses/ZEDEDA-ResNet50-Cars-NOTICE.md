# ZEDEDA ResNet50 Cars

Files:
- `resnet50_cars_enhanced.onnx`
- `stanford_cars_labels.txt`

Model repository:
https://huggingface.co/zededa/resnet50-cars

The model repository currently declares the license as Apache-2.0.

The model is a ResNet50 model fine-tuned on the Stanford Cars dataset and is
provided/maintained by ZEDEDA. The repository documents 196 make/model/year
classes.

A copy of the Apache License 2.0 is included as `Apache-2.0.txt`.

## Stanford Cars note

The model was trained on Stanford Cars. The ZEDEDA model repository's
Apache-2.0 declaration applies to that model repository; it should not be
silently treated as a blanket relicensing of every upstream dataset asset.

Before a public or commercial redistribution, verify the terms applicable to
the exact model and any dataset-derived artifacts included in the release.
